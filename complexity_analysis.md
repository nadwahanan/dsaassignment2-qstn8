# Complexity Analysis

## Merge Sort

| Case | Time Complexity |
|---|---|
| Best Case | O(n log n) |
| Average Case | O(n log n) |
| Worst Case | O(n log n) |

Additional Space: **O(n)**

## Quick Sort

| Case | Time Complexity |
|---|---|
| Best Case | O(n log n) |
| Average Case | O(n log n) |
| Worst Case | O(n²) |

Additional Space: **O(log n) average**

## Summary

Merge Sort has a guaranteed O(n log n) worst-case time complexity. Quick Sort has O(n log n) average performance but can reach O(n²) in the worst case.
